# Quiz de Aikya — Realidades 3

Práctica interactiva de **pretérito e imperfecto** basada en temas de *Realidades 3*, preparada por Super Spanish.

## Contenido
- Explicaciones contrastivas español–inglés para decidir entre pretérito e imperfecto.
- Actividades de reconocimiento del contexto y párrafos con verbos para conjugar.
- Ayudas en inglés al pasar el cursor o tocar los elementos señalados.
- Corrección y retroalimentación automáticas.

## Cómo abrirlo
Abre el archivo `index.html` en Chrome; no requiere instalación.

## GitHub Pages
En **Settings → Pages**, elige **Deploy from a branch**, selecciona **main** y **/(root)**. Una vez publicado, la dirección habitual será:

https://spanishwithpaula.github.io/Aikya-Realidades-3-Quiz/

El enlace de Pages solo funcionará después de activar y completar el despliegue.
